## Key Technical Features
- **Pseudo-3D Perspective Projection:** Calculated road curvature, hills, and depth scaling using custom trigonometry and projection math rather than a pre-built 3D engine.
- **Dynamic Track & Collision Physics:** Implemented opponent AI vehicles, off-road friction slowdown, and sprite collision detection.
- **Custom Game Loop:** Built smooth frame-rate-independent movement, lap timing, and score tracking.

## How to Run
1. Clone or download this repository.
2. Install dependencies: `pip install pygame`
3. Run the main script: `python main.py` *(change `main.py` to your actual starting file name)*
